# Project Metrics and KPI Definitions

## 1. Purpose

This document defines the key performance indicators used to monitor the fictional banking application modernization project.

All metrics and targets are illustrative and created for portfolio demonstration purposes.

## 2. Project Performance Metrics

| KPI                     | Definition                                                       | Illustrative Target  |
| ----------------------- | ---------------------------------------------------------------- | -------------------- |
| Schedule Performance    | Percentage of milestones completed on or before the planned date | 90% or higher        |
| Budget Variance         | Difference between actual and planned project spending           | Within 5%            |
| Requirements Completion | Percentage of approved requirements completed                    | 95% or higher        |
| Defect Closure          | Percentage of identified defects resolved before release         | 95% or higher        |
| Risk Mitigation         | Percentage of high-priority risks with mitigation plans          | 100%                 |
| UAT Completion          | Percentage of planned user acceptance tests completed            | 100% before sign-off |

## 3. Reporting Frequency

* Project team: Weekly
* Project manager: Weekly
* Steering committee: Monthly
* Critical risks and blockers: Escalated as needed

## 4. Escalation Guidelines

Issues that threaten critical milestones, approved budget, regulatory requirements, or release readiness should be escalated to the appropriate project sponsor or governance forum.

## 5. Data Disclaimer

All project scenarios, metrics, targets, and data in this document are fictional. They do not represent actual banking, employer, or client project information.
